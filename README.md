## 🤖 Overview

MORT is an OCR-based translation tool designed for manga and comic images, detecting text bubbles and replacing them with translated text in the correct position.

Whether you're a newcomer or a veteran, MORT OCR Translator provides the tools you need to get the most out of your ai tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.
